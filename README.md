## 🛠️ How to Run

**Prerequisites:** Java 17+ and a terminal.

```bash
# Compile
javac arrays/*.java

# Run
java -cp arrays *
```

Or open the project in any IDE (IntelliJ IDEA / VS Code / Eclipse).
